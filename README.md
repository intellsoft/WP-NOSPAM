# 🛡️ NO SPAM — افزونه ضد اسپم هانی‌پات برای وردپرس

**نسخه:** ۲.۴.۰۲  
**سازگار با:** وردپرس ۵.۰ به بالا  
**مجوز:** GPLv2 or later  
**وب‌سایت:** [IntellSoft.ir](https://intellsoft.ir)

---

## 📌 معرفی

**NO SPAM** یک افزونه سبک، سریع و کاملاً رایگان برای محافظت از فرم‌های وردپرس در برابر ربات‌های اسپم است. این افزونه با استفاده از تکنیک **Honeypot** (تله عسل) ربات‌ها را بدون نیاز به کپچا یا مزاحمت برای کاربران واقعی شناسایی و مسدود می‌کند.

---

## ✨ ویژگی‌های کلیدی

- 🍯 **فناوری Honeypot پیشرفته**  
  یک فیلد مخفی به فرم‌ها اضافه می‌شود که فقط ربات‌ها آن را پر می‌کنند. کاربران عادی هرگز آن را نمی‌بینند.

- 🔄 **تغییر خودکار نام فیلد هر روز**  
  نام فیلد تله به‌طور خودکار روزانه تغییر می‌کند تا ربات‌ها نتوانند خود را با الگوی ثابت وفق دهند. بدون نیاز به دخالت مدیر!

- 🧩 **سازگاری گسترده با فرم‌سازها**  
  پشتیبانی کامل از محبوب‌ترین افزونه‌های فرم‌ساز وردپرس:
  - Contact Form 7
  - WPForms
  - Gravity Forms
  - Elementor Pro Forms
  - Fluent Forms
  - Formidable Forms
  - Divi Contact Form
  - Caldera Forms
  - Toolset Forms
  - و همچنین فرم‌های نظرات، ثبت‌نام، ورود و فراموشی رمز عبور وردپرس

- 📊 **آمار زنده در داشبورد**  
  ویجت داشبورد و صفحه آمار، تعداد اسپم‌های مسدود شده **امروز، این هفته، این ماه و کل** را نمایش می‌دهد.

- ⚡ **بسیار سبک و بهینه**  
  بدون هیچ‌گونه تماس با سرورهای خارجی، بدون API و بدون کند کردن سایت.

- 🚫 **بدون نیاز به کپچا**  
  کاربران واقعی هیچ مرحله اضافی یا مزاحمتی تجربه نمی‌کنند.

- 🛠 **تنظیمات ساده و کاربردی**  
  پنل مدیریت با زبانه‌های تنظیمات، آمار و نسخه حرفه‌ای، همه در منوی اختصاصی **NO SPAM**.

- 🔇 **بدون پیام‌های تبلیغاتی روی فرم‌ها**  
  پیام‌های تست مدیر به طور کامل حذف شده است تا تجربه کاربری تمیزی داشته باشید.

---

## 🚀 نصب و راه‌اندازی

1. پوشه `honeypot` را در مسیر `/wp-content/plugins/` آپلود کنید.
2. از پیشخوان وردپرس افزونه را فعال کنید.
3. تنظیمات را از منوی **NO SPAM** بررسی کنید (تنظیمات پیش‌فرض برای اکثر سایت‌ها مناسب است).
4. تمام! حالا فرم‌های شما در برابر اسپم محافظت می‌شوند.
